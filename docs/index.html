What it does

  • Scans video files every N frames and detects every face
  • You name unfamiliar faces once — the app learns who's who
  • Searches your library: pick a person, see every video and timecode they appear in
  • Browse thumbnail galleries of each person's appearances
  • Everything stored locally in SQLite — no servers, no telemetry

Other platforms

On Linux or macOS, clone the repo and run python main.py. Full install steps are in the README.
